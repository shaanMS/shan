Chapter 04 · Bahut Important!

Turbo C vs GCC — Fark Kyun?

Tumhare college me shayad Turbo C use hota hai, aur tumhare laptop pe GCC (ya online compiler). Dono me bohot bada fark hai — aur agar yeh nahi pata toh program baar-baar fail hoga. Chalo samjhte hain!

🔴 Turbo C — Purana Zamana

  • Bana tha 1989-90 me, jab computers 16-bit the
  • Sirf 64 KB tak ka array bana sakta hai — usse bada NAHI
  • int sirf 2 bytes ka hota hai
  • Array ka size fixed hona chahiye (compile time pe pata ho)
  • // comment bhi nahi support karta (C89 me nahi tha)
  • clrscr(), getch() jaise functions hain

🟢 GCC — Modern Zamana

  • 32-bit aur 64-bit dono support karta hai
  • Array ka size RAM jitna bada ho sakta hai
  • int 4 bytes ka hota hai
  • Variable size arrays ban sakte hain (VLA)
  • C99, C11, C17 — sab modern features hain
  • Linux, Mac, Windows sab pe chalta hai
⚠️
Yeh yaad rakhna: Agar tumhara code Turbo C me chal raha hai aur GCC me nahi (ya ulta) — 90% chance hai ki problem 64 KB limit ya VLA ki hai. Neeche wale chapters me detail me samjhenge.
📚
Biology analogy: Turbo C ek purani microscope hai — kaam karti hai, lekin sirf choti cheezein dekh sakti hai. GCC ek modern electron microscope hai — bada, flexible, aur bahut kuch kar sakta hai. Dono se kaam hota hai, par naye experiments ke liye naya instrument chahiye!

Chapter 05 · Turbo C ki sabse badi problem

Variable Length Array (VLA)

Socho user input karega ki uska DNA sequence kitna lamba hai — 10 bases ya 1000. Array ka size toh runtime pe pata chalega, compile time pe nahi. Yahan Turbo C fail ho jaata hai. 😰

🔴 Turbo C — FAIL

#include <stdio.h>

int main() {
    int n;
    printf("DNA length? ");
    scanf("%d", &n);
    char dna[n];   /* ❌ ERROR!
       Turbo C me size fixed hona chahiye */
    return 0;
}
⛔
Turbo C kehta hai: "Array size must be a constant!"

🟢 GCC — PERFECT

#include <stdio.h>

int main() {
    int n;
    printf("DNA length? ");
    scanf("%d", &n);
    char dna[n];   /* ✅ Chal gaya!
       C99 se VLA support hai */
    return 0;
}
✅
GCC me C99 se yeh feature aata hai. Bohot handy hai!

GCC me VLA check kaise karo?

gcc -std=c90 -pedantic code.c   # Warning aayegi: "ISO C90 forbids VLA"
gcc -std=c99 -pedantic code.c   # ✅ Bilkul saaf, koi warning nahi

🔥 Turbo C me Workaround — malloc() ka Jaadu

Turbo C me VLA nahi hai, lekin dynamic memory se kaam ho jaata hai: 

#include <stdlib.h>
#include <stdio.h>

int main() {
    int n, i;
    char *dna;   /* pointer, array nahi */

    printf("DNA length? ");
    scanf("%d", &n);

    dna = (char *)malloc(n * sizeof(char));  /* runtime pe memory mil gayi */
    if (dna == NULL) {
        printf("Memory nahi mili!\n");
        return 1;
    }

    printf("Enter DNA: ");
    scanf("%s", dna);

    printf("Tumhara DNA: %s\n", dna);

    free(dna);   /* zaroor free karo! */
    return 0;
}
💡
Rule of thumb: Turbo C me ho? Toh malloc() tumhara best friend hai. GCC me ho? Toh VLA use kar sakte ho, lekin bade arrays ke liye malloc() hi safe hai.

Chapter 08 · Operations

Traversal — Har Ek Pe Ek Nazar

Traversal matlab array ke har element pe jaana — ek-ek karke. Jaise teacher attendance lagate waqt har roll number call karti hai. Simple loop se hota hai.

➡️ Aage Ki Taraf (Forward)

int marks[5] = {10, 20, 30, 40, 50};
int n = 5;

for (int i = 0; i < n; i++) {
    printf("marks[%d] = %d\n", i, marks[i]);
}

Index 0 se n-1 tak

⬅️ Peeche Ki Taraf (Backward)

int marks[5] = {10, 20, 30, 40, 50};
int n = 5;

for (int i = n - 1; i >= 0; i--) {
    printf("marks[%d] = %d\n", i, marks[i]);
}

n-1 se 0 tak (ulti direction)

Chapter 09

Element Daalna aur Nikalna

Socho class me naya student aaya beech me — uske peeche wale sabko ek seat peeche khisakna padega. Array me bhi exactly yahi hota hai!

➕ Insert at Position

void insertElement(int arr[], int *n,
                   int pos, int value) {
    if (pos < 0 || pos > *n) {
        printf("Galat position!\n");
        return;
    }
    /* elements ko right shift karo */
    for (int i = *n; i > pos; i--) {
        arr[i] = arr[i - 1];
    }
    arr[pos] = value;
    (*n)++;
}

➖ Delete at Position

void deleteElement(int arr[], int *n, int pos) {
    if (pos < 0 || pos >= *n) {
        printf("Galat position!\n");
        return;
    }
    /* elements ko left shift karo */
    for (int i = pos; i < *n - 1; i++) {
        arr[i] = arr[i + 1];
    }
    (*n)--;
}

Chapter 10

Searching — Ek Element Dhoondhna

Array me kisi specific value ko dhoondhna. Do tareeke hain — ek simple (lekin slow), ek smart (lekin sorted chahiye).

🔍 Linear Search · O(n)

Ek-ek karke check karo. Kisi bhi array pe chalta hai. 

int linearSearch(int arr[], int n, int key) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == key)
            return i;    /* mila! */
    }
    return -1;   /* nahi mila */
}

⚡ Binary Search · O(log n)

Beech se check karo, half discard karo. Sirf sorted array pe. 

int binarySearch(int arr[], int low,
                 int high, int key) {
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == key)  return mid;
        else if (arr[mid] < key) low = mid + 1;
        else                     high = mid - 1;
    }
    return -1;
}
Interactive · Search Race — dono algorithms compare karo!
Key daalo aur koi algorithm chuno.
📖
Dictionary analogy: Linear search = page 1 se ek-ek page palat ke shabd dhoondhna. Binary search = dictionary khol ke beech me jao, dekho shabd pehle hai ya baad me, aur aadhi dictionary discard kar do. Binary search 1000x fast hota hai!
💡
Numbers: n = 10,00,000 ke liye — Linear search ko 10 lakh comparisons lag sakte hain, par Binary search ko sirf 20. Ye hai O(log n) ki power!

Chapter 11

Sorting qsort() se — Ready-made!

C me already ek powerful sorting function bana hua hai — <stdlib.h> me qsort(). Isko use karo, apna sorting algorithm likhne ki zaroorat nahi!

Function Signature

void qsort(void *base, size_t nelem, size_t size,
           int (*compar)(const void *, const void *));
ParameterKya batata hai
baseArray ka pehla element ka address (array ka naam)
nelemKitne elements hain
sizeHar element kitne bytes ka hai
comparComparison function — batata hai kaun bada hai

Poora Working Example

#include <stdio.h>
#include <stdlib.h>

/* Comparison function — chhota bada kaun? */
int compare(const void *a, const void *b) {
    return (*(int *)a - *(int *)b);
}

int main(void) {
    int marks[] = {64, 25, 12, 22, 11};
    int n = sizeof(marks) / sizeof(marks[0]);

    qsort(marks, n, sizeof(int), compare);

    for (int i = 0; i < n; i++)
        printf("%d ", marks[i]);
    /* Output: 11 12 22 25 64 */

    return 0;
}

⬆️ Chhote se Bade (Ascending)

return (*(int *)a - *(int *)b);

⬇️ Bade se Chhote (Descending)

return (*(int *)b - *(int *)a);

Chapter 12

Copy, Reverse aur Fill

📋 Copy Karna

Ek array ki cheezein dusre me daalna.

int src[5] = {1,2,3,4,5};
int dest[5];

memcpy(dest, src, sizeof(src));

/* ya manual loop */
for (int i = 0; i < 5; i++)
    dest[i] = src[i];

🔄 Reverse Karna

Ulta kar dena — pehla aakhri, aakhri pehla.

void reverse(int arr[], int n) {
    for (int i = 0; i < n / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[n - 1 - i];
        arr[n - 1 - i] = temp;
    }
}

🧹 Fill Karna

Sab elements ko ek value se bhar dena.

int arr[100];

/* sab bytes 0 karo */
memset(arr, 0, sizeof(arr));

/* Warning! Yeh 1 nahi bharega */
memset(arr, 1, sizeof(arr));
⚠️
memset ka trap: memset() bytes set karta hai, elements nahi. memset(arr, 1, sizeof(arr)) har int ko 1 nahi banata — har byte ko 1 banata hai, jisse garbage value jaise 0x01010101 aata hai. Non-zero fill ke liye loop use karo.
💡
memcpy() aur memset() <string.h> me hote hain aur raw bytes pe kaam karte hain — isliye super fast hain.

Chapter 13

Array ko Function me Bhejna

Jab tum array kisi function me bhejte ho, C actually pehle element ka address bhejta hai. Array "decay" ho jaata hai pointer me. Yeh samajhna zaroori hai!

Teen Tarah se Likh Sakte Ho — Sab Same Hai

void printArray(int arr[], int size);      /* sabse readable */
void printArray(int *arr, int size);       /* pointer se */
void printArray(int arr[100], int size);   /* size IGNORE ho jaata hai */

Working Example

#include <stdio.h>

void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int marks[5] = {10, 20, 30, 40, 50};
    printArray(marks, 5);   /* array ka naam = pointer */
    return 0;
}
⛔
Bahut important: Array ka size apne aap nahi jaata function me. Tumhe alag se size bhejna padta hai. Aur C me koi range checking nahi hoti — arr[10] likhna 5-element array me undefined behavior hai, program crash ho sakta hai!

🔬 Kyun Size Zaroori Hai — Trap Dekho

void broken(int arr[]) {
    /* sizeof(arr) = 8 bytes (pointer ka size)
       array ka size NAHI! */
    int n = sizeof(arr) / sizeof(arr[0]);   /* ❌ GALAT */
    printf("%d\n", n);
}

int main(void) {
    int marks[100];
    broken(marks);   /* 2 ya 1 print karega — bilkul galat! */
    return 0;
}

Function ke andar arr sirf ek pointer hai. sizeof pointer ka size deta hai, array ka nahi. Hamesha size alag se bhejo.

int arrayMax(int arr[], int size) {

int arrayMin(int arr[], int size) {
    int min = arr[0];

int arraySum(int arr[], int size) {
    int sum = 0;
    for (int i = 0; i < size; i++)

double arrayAverage(int arr[], int size) {
    return (double)arraySum(arr, size) / size;

Chapter 15

2D Array — Table Jaisa Array

Ek simple array ek line hai. Do-dimensional (2D) array ek table hai — rows aur columns ke saath. Jaise Excel sheet ya class ki seating arrangement!

2D Array Banana aur Use Karna

int marks[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

/* row 1, column 2 ka element */
printf("%d\n", marks[1][2]);  /* 6 */

/* poora traverse karo */
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        printf("%4d", marks[i][j]);
    }
    printf("\n");
}

Memory Me Kaise Store Hota Hai?

Dono compilers me row-major order hota hai — pehle row 0, phir row 1...

marks[3][3] ka flat view — 9 contiguous int

Address Formula

💡
2D array T a[R][C] me, element a[i][j] ka address:

addr = base + (i * C + j) * sizeof(T)

Jaise int marks[3][3] me marks[1][2] — base + (1*3 + 2) * 4 = base + 20 bytes (GCC me).
📋
Biology example: Class ki attendance — 40 students × 30 days ka record. att[student][day] se ek student ke ek din ka attendance turant mil jaata hai. Yeh 2D array hai!
⚠️
Turbo C me dhyan se: int big[200][200] = 200 × 200 × 2 = 80,000 bytes — 64 KB limit se bada hai, compile hi nahi hoga. GCC me sirf 160,000 bytes hai, chal jaayega.

🎯 Golden Rules — Yaad Rakho

  • Index 0 se size-1 tak. Ek kam ya zyada mat karo.
  • Function me size hamesha alag se bhejo — woh saath nahi jaata.
  • Bounds ke bahar access mat karo. C rokti nahi — OS rokti hai (crash).
  • String ke liye size + 1 bytes rakho ('\0' ke liye).
  • Bade arrays ke liye malloc() use karo — khaas kar Turbo C me.
  • Har malloc() ka ek free() hona chahiye.

Poora Working Project

Yeh ek menu-driven program hai jo sab kuch ek jagah dikhata hai — display, max, min, search, reverse, sort. Turbo C aur GCC dono me chalega. 

#include <stdio.h>
#include <stdlib.h>

/* ---------- Function declarations ---------- */
void display(int arr[], int n);
int  findMax(int arr[], int n);
int  findMin(int arr[], int n);
int  linearSearch(int arr[], int n, int key);
void reverse(int arr[], int n);
int  compare(const void *a, const void *b);

/* ---------- Main ---------- */
int main(void) {
    int marks[100];
    int n, choice, key, pos;

    printf("=== ARRAY OPERATIONS DEMO ===\n");
    printf("Kitne students ke marks? ");
    scanf("%d", &n);

    printf("Ab %d marks daalo:\n", n);
    for (int i = 0; i < n; i++)
        scanf("%d", &marks[i]);

    do {
        printf("\n--- MENU ---\n");
        printf("1. Display\n");
        printf("2. Max Dhundo\n");
        printf("3. Min Dhundo\n");
        printf("4. Search\n");
        printf("5. Reverse\n");
        printf("6. Sort\n");
        printf("7. Exit\n");
        printf("Choice: ");
        scanf("%d", &choice);

        switch (choice) {
            case 1:
                display(marks, n);
                break;

            case 2:
                printf("Max = %d\n", findMax(marks, n));
                break;

            case 3:
                printf("Min = %d\n", findMin(marks, n));
                break;

            case 4:
                printf("Key daalo: ");
                scanf("%d", &key);
                pos = linearSearch(marks, n, key);
                if (pos != -1)
                    printf("Mila! Index %d pe\n", pos);
                else
                    printf("Nahi mila\n");
                break;

            case 5:
                reverse(marks, n);
                printf("Reverse ho gaya!\n");
                break;

            case 6:
                qsort(marks, n, sizeof(int), compare);
                printf("Sort ho gaya!\n");
                break;

            case 7:
                printf("Bye!\n");
                break;

            default:
                printf("Galat choice!\n");
        }
    } while (choice != 7);

    return 0;
}

/* ---------- Function implementations ---------- */

void display(int arr[], int n) {
    printf("Array: ");
    for (int i = 0; i < n; i++)
        printf("%d ", arr[i]);
    printf("\n");
}

int findMax(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++)
        if (arr[i] > max)
            max = arr[i];
    return max;
}

int findMin(int arr[], int n) {
    int min = arr[0];
    for (int i = 1; i < n; i++)
        if (arr[i] < min)
            min = arr[i];
    return min;
}

int linearSearch(int arr[], int n, int key) {
    for (int i = 0; i < n; i++)
        if (arr[i] == key)
            return i;
    return -1;
}

void reverse(int arr[], int n) {
    for (int i = 0; i < n / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[n - 1 - i];
        arr[n - 1 - i] = temp;
    }
}

int compare(const void *a, const void *b) {
    return (*(int *)a - *(int *)b);
}
