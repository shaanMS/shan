Chapter 01 · Fundamentals

What is an Array?

Consider a scenario where you need to store the marks of 10 students. Declaring 10 separate variables is impractical: 

int marks1, marks2, marks3, marks4, marks5;
int marks6, marks7, marks8, marks9, marks10;
/* Inefficient and difficult to manage */

Instead, a single array stores all of them: 

int marks[10];   /* One declaration for 10 elements */

Definition: An array is a collection of elements of the same data type stored in contiguous memory locations. Each element is accessed by its index, which starts from 0.

Chapter 02 · Applications

Real-World Applications of Arrays

Arrays are used extensively in software systems. The following examples illustrate common practical applications:

📊 Student Marks Management

Storing marks of 5 subjects for a student:

int marks[5] = {85, 92, 78, 95, 88};
/* marks[0] = Physics, marks[1] = Chemistry, ... */
🎓
Average, total, highest marks — all computed with a single loop.

📱 Contact Management

Storing phone numbers of 10 contacts:

long contacts[10] = {
    9876543210, 9123456789, /* ... */
};
📞
Retrieve the 5th contact's number directly: contacts[4]

🏏 Cricket Score Tracking

Runs scored in 6 balls by a batsman:

int runs[6] = {4, 0, 6, 1, 2, 4};
/* Total = 17 runs */
🏏
Total, strike rate, highest score — all easily computed.

🛒 Shopping Cart

Prices of 4 items in a shopping cart:

float cart[4] = {499.0, 1299.5, 250.0, 89.99};
/* Compute total bill */
🛍️
Count items, compute total price — all with a single loop.

🎵 Playlist Management

Storing names of 5 songs in a playlist:

char playlist[5][30] = {
    "Kesariya", "Tum Hi Ho", /* ... */
};
🎶
Access the 3rd song: playlist[2]

🌡️ Daily Temperature Records

Storing 30 days of temperature readings:

float temp[30] = {28.5, 29.2, /* ... */};
/* Max, min, average over the month */
🌤️
Hottest day, coldest day, monthly average — all computed easily.
📌
Key principle: Whenever a group of related data needs to be stored and accessed by index — marks, contacts, songs, scores, prices — arrays provide the appropriate solution.

Chapter 03

Declaration & Initialization

1 · Declaration Syntax

The general syntax for declaring an array:

data_type  array_name[size];

/* Examples: */
int    marks[10];       /* 10 integers */
float  prices[5];       /* 5 floating-point values */
char   name[20];        /* 20 characters */
double matrix[3][3];    /* 3x3 two-dimensional array */

Memory Representation

int marks[5] = {85, 92, 78, 95, 88};

Memory Addresses

marks[0]1000
marks[1]1004
marks[2]1008
marks[3]1012
marks[4]1016

Each int occupies 4 bytes in GCC. The address increments by 4.

2 · Initialization Methods

int marks[5] = {85, 92, 78, 95, 88};
/* All 5 elements initialized explicitly. Safest approach. */
int marks[5] = {85, 92};
/* marks[0]=85, marks[1]=92
   marks[2], [3], [4] => 0 ONLY if the array is 'static'
   Otherwise, they contain indeterminate (garbage) values. */
⚠️
Elements not explicitly initialized have indeterminate values unless the array has static storage duration. For local (automatic) arrays, always initialize all elements, or use {0} to set everything to zero.
int marks[] = {85, 92, 78, 95, 88};
/* Compiler counts the initializers -> size = 5 */
📌
To obtain the element count safely: sizeof(marks) / sizeof(marks[0])
int marks[10] = { [2] = 85, [7] = 92 };
/* Only indices 2 and 7 are set; the rest are 0
   Supported in GCC (C99), NOT in Turbo C */
⚠️
Turbo C does not support designated initializers (it implements C89/C90). GCC supports this feature from C99 onwards.
int att[100] = { [0 ... 9] = 1, [10 ... 98] = 2, 3 };
/* Index 0-9   = 1
   Index 10-98 = 2
   Index 99    = 3 */
📌
Range designators are a GCC extension (also supported by Clang). They are not available in Turbo C.

Chapter 04 · Compiler Differences

Turbo C vs GCC — Key Differences

Many institutions use Turbo C for teaching, while modern development environments use GCC. There are significant differences between the two that students must understand to avoid compilation errors.

🔴 Turbo C — Legacy Compiler

  • Designed for 16-bit systems (late 1980s)
  • Maximum array size: 64 KB (segment limit)
  • int occupies 2 bytes
  • Array size must be a compile-time constant
  • Does not support // comments

🟢 GCC — Modern Compiler

  • Supports 32-bit and 64-bit architectures
  • Array size limited only by available RAM
  • int occupies 4 bytes
  • Supports Variable Length Arrays (VLA) in C99
  • Available on Linux, macOS, and Windows
⚠️
Important: If a program compiles in Turbo C but fails in GCC (or vice versa), the cause is usually the 64 KB limit or VLA support.

Turbo C Workaround — Using malloc()

#include <stdlib.h>
#include <stdio.h>

int main() {
    int n, i;
    int *marks;   /* pointer, not array */

    printf("Enter number of subjects: ");
    scanf("%d", &n);

    marks = (int *)malloc(n * sizeof(int));  /* runtime allocation */
    if (marks == NULL) {
        printf("Memory allocation failed!\n");
        return 1;
    }

    for (i = 0; i < n; i++) {
        printf("Enter marks for subject %d: ", i + 1);
        scanf("%d", &marks[i]);
    }

    printf("Marks: ");
    for (i = 0; i < n; i++)
        printf("%d ", marks[i]);

    free(marks);   /* Always free allocated memory */
    return 0;
}

Insertion & Deletion

Inserting or deleting an element at a specific position requires shifting the remaining elements. Insertion shifts elements to the right; deletion shifts elements to the left.

➕ Insertion at a Position

void insertElement(int arr[], int *n,
                   int pos, int value) {
    if (pos < 0 || pos > *n) {
        printf("Invalid position!\n");
        return;
    }
    /* Shift elements to the right */
    for (int i = *n; i > pos; i--) {
        arr[i] = arr[i - 1];
    }
    arr[pos] = value;
    (*n)++;
}

➖ Deletion at a Position

void deleteElement(int arr[], int *n, int pos) {
    if (pos < 0 || pos >= *n) {
        printf("Invalid position!\n");
        return;
    }
    /* Shift elements to the left */
    for (int i = pos; i < *n - 1; i++) {
        arr[i] = arr[i + 1];
    }
    (*n)--;
}

🔍 Linear Search · O(n)

Checks each element sequentially. Works on any array. 

int linearSearch(int arr[], int n, int key) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == key)
            return i;    /* found */
    }
    return -1;   /* not found */
}

⚡ Binary Search · O(log n)

Repeatedly divides the search interval. Requires a sorted array. 

int binarySearch(int arr[], int low,
                 int high, int key) {
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == key)  return mid;
        else if (arr[mid] < key) low = mid + 1;
        else                     high = mid - 1;
    }
    return -1;
}

Complete Working Example

#include <stdio.h>
#include <stdlib.h>

/* Comparison function for integers (ascending) */
int compare(const void *a, const void *b) {
    return (*(int *)a - *(int *)b);
}

int main(void) {
    int scores[] = {64, 25, 12, 22, 11};
    int n = sizeof(scores) / sizeof(scores[0]);

    qsort(scores, n, sizeof(int), compare);

    for (int i = 0; i < n; i++)
        printf("%d ", scores[i]);
    /* Output: 11 12 22 25 64 */

    return 0;
}

⬆️ Ascending Order

⬇️ Descending Order

return (*(int *)b - *(int *)a);

void reverse(int arr[], int n) {
    for (int i = 0; i < n / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[n - 1 - i];
        arr[n - 1 - i] = temp;
    }
}

void printArray(int arr[], int size);      /* most readable */
void printArray(int *arr, int size);       /* explicit pointer */

Working Example

#include <stdio.h>

void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main(void) {
    int marks[5] = {10, 20, 30, 40, 50};
    printArray(marks, 5);   /* array name decays to pointer */
    return 0;
}
⛔
Critical: The array size is NOT passed automatically. It must be passed separately. C performs no bounds checking — accessing arr[10] in a 5-element array is undefined behavior.

🔬 Why Size Matters — A Common Pitfall

void broken(int arr[]) {
    /* sizeof(arr) == sizeof(int*)  ->  8 bytes on 64-bit GCC

    int n = sizeof(arr) / sizeof(arr[0]);   /* ❌ INCORRECT */
    printf("%d\n", n);
}

int main(void) {
    int marks[100];
    broken(marks);   /* prints 2 (or 1) — completely wrong */
    return 0;

int arrayMax(int arr[], int size) {
    int max = arr[0];
    for (int i = 1; i < size; i++)

    return max;

int arrayMin(int arr[], int size) {
    int min = arr[0];
    for (int i = 1; i < size; i++)

Declaration and Access

int marks[3][3] = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}

printf("%d\n", marks[1][2]);  /* 6 */

Memory Layout (Row-Major Order)

Both Turbo C and GCC store 2D arrays in row-major order — row 0 first, then row 1, and so on.

Flat view of marks[3][3] — 9 contiguous integers

Address Formula

📌
For a 2D array T a[R][C], the address of a[i][j] is:

addr = base + (i * C + j) * sizeof(T)

For example, in int marks[3][3], marks[1][2] is at base + (1*3 + 2) * 4 = base + 20 bytes (GCC).
⚠️
Turbo C limitation: int big[200][200] = 200 × 200 × 2 = 80,000 bytes — exceeds the 64 KB limit, so it will not compile. In GCC it is only 160,000 bytes and works fine.

strchr(name, 'e');       /* first occurrence of 'e' */
strstr(name, "ell");     /* first occurrence of substring */

Always allocate size + 1 bytes. A 5-character string needs char s[6] to hold the terminating '\0'. Forgetting this causes buffer overflows — the leading cause of security vulnerabilities in C programs.

🎯 Key Rules to Remember

  • Indices run from 0 to size-1.
  • Always pass the size to functions — it does not travel with the array.
  • Never read or write out of bounds. C performs no checks.
  • Reserve size + 1 bytes for strings (for '\0').

Chapter 18 · Project

Complete Working Project

A menu-driven "Student Marks Manager" program that demonstrates all the concepts covered. Works on both Turbo C and GCC. 

#include <stdio.h>
#include <stdlib.h>

/* ---------- Function prototypes ---------- */
void display(int arr[], int n);
int  findMax(int arr[], int n);
int  findMin(int arr[], int n);
int  linearSearch(int arr[], int n, int key);
void reverse(int arr[], int n);
int  compare(const void *a, const void *b);

/* ---------- Main ---------- */
int main(void) {
    int marks[100];
    int n, choice, key, pos;

    printf("=== STUDENT MARKS MANAGER ===\n");
    printf("Enter number of students: ");
    scanf("%d", &n);

    printf("Enter %d marks:\n", n);
    for (int i = 0; i < n; i++)
        scanf("%d", &marks[i]);

    do {
        printf("\n--- MENU ---\n");
        printf("1. Display\n");
        printf("2. Find Maximum\n");
        printf("3. Find Minimum\n");
        printf("4. Search\n");
        printf("5. Reverse\n");
        printf("6. Sort\n");
        printf("7. Exit\n");
        printf("Choice: ");
        scanf("%d", &choice);

        switch (choice) {
            case 1: display(marks, n); break;
            case 2: printf("Max = %d\n", findMax(marks, n)); break;
            case 3: printf("Min = %d\n", findMin(marks, n)); break;
            case 4:
                printf("Enter key: ");
                scanf("%d", &key);
                pos = linearSearch(marks, n, key);
                if (pos != -1)
                    printf("Found at index %d\n", pos);
                else
                    printf("Not found\n");
                break;
            case 5: reverse(marks, n); printf("Reversed!\n"); break;
            case 6: qsort(marks, n, sizeof(int), compare);
                    printf("Sorted!\n"); break;
            case 7: printf("Exiting...\n"); break;
            default: printf("Invalid choice!\n");
        }
    } while (choice != 7);

    return 0;
}

/* ---------- Implementations ---------- */
void display(int arr[], int n) {
    printf("Marks: ");
    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
}

int findMax(int arr[], int n) {
    int max = arr[0];
    for (int i = 1; i < n; i++)
        if (arr[i] > max) max = arr[i];
    return max;
}

int findMin(int arr[], int n) {
    int min = arr[0];
    for (int i = 1; i < n; i++)
        if (arr[i] < min) min = arr[i];
    return min;
}

int linearSearch(int arr[], int n, int key) {
    for (int i = 0; i < n; i++)
        if (arr[i] == key) return i;
    return -1;
}

void reverse(int arr[], int n) {
    for (int i = 0; i < n / 2; i++) {
        int temp = arr[i];
        arr[i] = arr[n - 1 - i];
        arr[n - 1 - i] = temp;
    }
}

int compare(const void *a, const void *b) {
    return (*(int *)a - *(int *)b);
}

Common Pitfalls & Best Practices

⚠️ Pitfall✅ Solution
Off-by-one errorsIndices run from 0 to n-1. Use i < n, not i <= n.
Out-of-bounds accessAlways check i < n. C performs no bounds checking — undefined behavior.
Forgetting '\0' for stringsAllocate size + 1 bytes for character arrays.
Not passing array sizeAlways pass size separately — sizeof inside a function gives pointer size.
Using uninitialized arraysInitialize before use: int a[10] = {0};
Turbo C 64 KB limitUse malloc() for large arrays.
VLA in Turbo CUse malloc() with a runtime size.
memset() on int arraysUse a loop — memset sets bytes, not elements.
Integer division in averageCast: (double)sum / n
Memory leaksEvery malloc() needs a matching free().
✅
Best practice: Compile with warnings enabled. gcc -Wall -Wextra -pedantic code.c catches most of these issues before the program even runs.
